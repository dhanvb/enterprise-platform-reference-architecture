# Architecture Decision Records

Architecture Decision Records document significant architectural decisions
made during the development of the Enterprise Platform Reference Architecture.

An ADR records:

- the context that required a decision;
- the decision taken;
- alternatives considered;
- positive and negative consequences;
- the current status of the decision.

## ADR Status Values

ADRs may have one of the following states:

- Proposed
- Accepted
- Rejected
- Superseded
- Deprecated
