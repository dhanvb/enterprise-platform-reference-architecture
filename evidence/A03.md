## 5. Security Control Coverage

### A03-R03: Closed-field Structural Validation

**Status:** Static verified

The JSON Schema uses `additionalProperties: false` to reject undeclared contract properties.

Unit tests verify rejection of unknown top-level and nested fields.

This establishes selected structural constraints.

### A03-R11: Credential Exposure Prevention

**Status:** Pending integration

The onboarding contract prohibits submission of credential values.

However, the existing JSON Schema does not reliably detect credentials embedded inside otherwise permitted text fields.

A separate credential-scanning mechanism and representative negative tests are required.

The current architecture does not claim complete credential detection.
